# Sample bursts

Six real camera-trap bursts (three stills each) from **Snapshot Serengeti** (University of Minnesota Lion Center),
distributed by [LILA BC](https://lila.science/datasets/snapshot-serengeti) under the
[Community Data License Agreement (permissive variant)](https://cdla.dev/permissive-1-0/).
Resized to 1280 pixels wide. Labels are the volunteer consensus from the dataset.
